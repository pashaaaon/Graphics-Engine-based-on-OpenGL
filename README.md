# Graphics-Engine-based-on-OpenGL
A simple C++ library for rendering 3D and 2D graphics. It has an easy-to-learn API and can be used for commercial and non-commercial development.

The project is built automatically using compile_run.exe (CMake is required).
The "Content" folder is used for 3D models and other assets required by your project.
main.cpp is the main entry point of your project and also contains example/demo code.

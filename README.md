# OpenGL-Graphics-Engine

### A simple C++ graphics engine for rendering 3D graphics. It has an easy-to-learn API and can be used for commercial and non-commercial development.


#### How to use:

- The project is built automatically using compile_run.bat on Windows or compile_run.sh from Linux with Wine (CMake and MinGW in PATH are required).

- The "Content" folder is used for 3D models and other assets required by your project.

- main.cpp is the main entry point of your project and also contains example/demo code.

- Windows only. Building on Linux through Wine is supported.
